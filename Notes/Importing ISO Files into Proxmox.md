On the Promox server put the ISO file in:

```shell
/var/lib/vz/template/iso
```

On Proxmox dashboard:
1. **Create VM**
2. Add a **Name** then click **Next**
3. Under **ISO Image** the ISO images in the folder above should auto populate.
